# SmartShop AI API

A prototype backend developed for **FETIN**, focused on exploring the concept of an intelligent shopping assistant.

The project uses **FastAPI and Python** to provide product management and search functionality that could support an AI-driven shopping experience.

## 💡 Project Idea

SmartShop AI was created as a prototype for a technology fair, exploring how software and Artificial Intelligence could improve the shopping experience.

The idea was to provide users with a system capable of helping them search and discover products based on information such as name, category, and price.

## ⚙️ API Features

The backend provides endpoints for product-related operations, including:

* Search products by name
* Search products by category
* Search products by price
* Create new products
* Manage product information

## 🛠️ Technologies

* Python
* FastAPI
* REST API
* Backend Development

## 🚀 Running the Project

Install the project dependencies and start the FastAPI application.

Example:

```bash
uvicorn main:app --reload
```

Once the application is running, the interactive API documentation can be accessed through FastAPI's Swagger interface.

## 🎯 Project Context

This project was developed as a prototype for **FETIN**, a technology and innovation fair.
